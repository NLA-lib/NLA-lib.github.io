::: definition decl:NLAlib.rbki name="Randomized block Krylov iteration"
For a matrix $\mathbf{A}$, a start block $\boldsymbol{\Omega}$ with $\ell$ columns, and $q$ blocks, form the column space generated by

$$\mathbf{Y}=[\mathbf{A}\boldsymbol{\Omega},\ (\mathbf{A}\mathbf{A}^{\mathsf{H}})\mathbf{A}\boldsymbol{\Omega},\ldots,(\mathbf{A}\mathbf{A}^{\mathsf{H}})^{q-1}\mathbf{A}\boldsymbol{\Omega}]$$

and return

$$\mathsf{rbki}(\mathbf{A},\boldsymbol{\Omega},q)=\mathbf{P}_{\mathbf{Y}}\mathbf{A}.$$

This is a deterministic function of $\mathbf{A}$, $\boldsymbol{\Omega}$, and $q$, over real or complex scalars. It is the zero matrix for $q=0$ and the range-finder approximation $\mathsf{rsvd}(\mathbf{A},\boldsymbol{\Omega})$ for $q=1$. Unlike subspace iteration, the block Krylov range retains all these powers.
:::
