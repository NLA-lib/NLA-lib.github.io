::: definition decl:NLAlib.rbki name="Randomized block Krylov iteration"
For a matrix $\mathbf{A}$, a start block $\mathbf\Omega$ with $\ell$ columns, and $q$ blocks, form the column space generated by

$$\mathbf{Y}=[\mathbf{A}\mathbf\Omega,\ (\mathbf{A}\mathbf{A}^{\mathsf{H}})\mathbf{A}\mathbf\Omega,\ldots,(\mathbf{A}\mathbf{A}^{\mathsf{H}})^{q-1}\mathbf{A}\mathbf\Omega]$$

and return

$$\mathsf{rbki}(\mathbf{A},\mathbf\Omega,q)=\mathbf{P}_{\mathbf{Y}}\mathbf{A}.$$

This is a deterministic function of $\mathbf{A}$, $\mathbf\Omega$, and $q$, over real or complex scalars. It is the zero matrix for $q=0$ and the range-finder approximation $\mathsf{rsvd}(\mathbf{A},\mathbf\Omega)$ for $q=1$. Unlike subspace iteration, the block Krylov range retains all these powers.
:::
