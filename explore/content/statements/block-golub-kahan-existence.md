::: theorem result:block-golub-kahan-existence name="A run exists for every input" id=existence
For every $\mathbf{A}$, every start block $\mathbf\Omega$, and every $q$, there are matrices $\mathbf{U},\mathbf{V},\mathbf{R}_0,\mathbf{R},\mathbf{S}$ forming an exact run. The definition is therefore never vacuous.
:::
