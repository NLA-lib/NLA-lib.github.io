::: theorem result:block-golub-kahan-existence name="A run exists for every input" id=existence
For either scalar field $\mathbb{K}\in\{\mathbb{R},\mathbb{C}\}$, every matrix $\mathbf{A}\in\mathbb{K}^{m\times n}$, start block $\boldsymbol{\Omega}\in\mathbb{K}^{n\times b}$, and $q\in\mathbb{N}$, there exist $\mathbf{U}\in\mathbb{K}^{m\times qb}$, $\mathbf{V}\in\mathbb{K}^{n\times(q+1)b}$, $\mathbf{R}_0\in\mathbb{K}^{b\times b}$, $\mathbf{R}\in\mathbb{K}^{qb\times qb}$, and $\mathbf{S}\in\mathbb{K}^{(q+1)b\times qb}$ forming an [exact block Golub–Kahan run](/explore/statements/4dfc5d02-1a58-53ba-8b1b-f151f3a1fa58/).
:::
