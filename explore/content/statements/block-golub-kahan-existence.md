::: theorem result:block-golub-kahan-existence name="A run exists for every input" id=existence
For every $\mathbf{A}$, every start block $\boldsymbol{\Omega}$, and every $q$, there are matrices $\mathbf{U},\mathbf{V},\mathbf{R}_0,\mathbf{R},\mathbf{S}$ forming an [exact run](/explore/statements/4dfc5d02-1a58-53ba-8b1b-f151f3a1fa58/). The definition is therefore never vacuous.
:::
