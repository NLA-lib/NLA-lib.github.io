::: definition name="Full orthogonalization method"
For a square system $\mathbf{A}\mathbf{x}=\mathbf{b}$, choose $\mathbf{x}_k\in\mathbf{x}_0+\mathcal K_k(\mathbf{A},\mathbf{r}_0)$ so that $\mathbf{r}_k=\mathbf{b}-\mathbf{A}\mathbf{x}_k$ is orthogonal to $\mathcal K_k(\mathbf{A},\mathbf{r}_0)$. Here $\mathbf{r}_0=\mathbf{b}-\mathbf{A}\mathbf{x}_0$. The projected equations must be solvable for the iterate to be defined.
:::
