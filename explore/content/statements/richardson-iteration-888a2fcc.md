::: definition name="Richardson iteration"
For $\mathbf{A}\mathbf{x}=\mathbf{b}$ and a fixed correction map $\mathbf{M}$, set $\mathbf{x}_{j+1}=\mathbf{x}_j+\mathbf{M}(\mathbf{b}-\mathbf{A}\mathbf{x}_j)$. A step size can be absorbed into $\mathbf{M}$. Defining the recurrence requires no convergence claim; the spectral hypotheses of the result below determine when the error decreases.
:::
