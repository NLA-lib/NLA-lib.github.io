::: definition name="Power iteration"
For a square matrix $\mathbf{A}$ and a nonzero starting vector, repeatedly set $\mathbf{y}_{j+1}=\mathbf{A}\mathbf{x}_j$ and normalize $\mathbf{x}_{j+1}=\mathbf{y}_{j+1}/\|\mathbf{y}_{j+1}\|_2$ whenever the numerator is nonzero. A Rayleigh quotient supplies an eigenvalue estimate. Convergence requires spectral and starting-vector assumptions.
:::
