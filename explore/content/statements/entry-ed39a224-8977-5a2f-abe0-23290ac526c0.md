::: theorem result:chebyshev-inequality name="Chebyshev's inequality"
As a failure probability: for a finite measure $\mu$, $X \in L^2$
and $t > 0$,
$$\mu\{t \le \lvert X - \mathbb{E} X\rvert\} \le \frac{\operatorname{Var} X}{t^2}\,,$$
with $\mathbb{E} X = \int X \, d\mu$.
The cited result is stated for a probability measure; this statement allows any finite measure.
:::
