::: theorem result:sylvester-rank-inequality name="Sylvester's rank inequality"
For $\mathbf{A}$ with column index $n$ and $\mathbf{B}$ with
row index $n$,
$\operatorname{rank} \mathbf{A} + \operatorname{rank} \mathbf{B}
\le \lvert n \rvert + \operatorname{rank}(\mathbf{A}\mathbf{B})$.
Horn and Johnson state it as $\operatorname{rank} \mathbf{A} + \operatorname{rank} \mathbf{B} - n
\le \operatorname{rank}(\mathbf{A}\mathbf{B})$; this form writes the equivalent inequality
additively and holds over any field.
:::
