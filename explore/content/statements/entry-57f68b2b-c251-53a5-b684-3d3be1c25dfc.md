::: theorem result:lidskii-singular-values name="Lidskii's inequality for singular values"
For matrices $\mathbf{A}$ and $\mathbf{E}$ of the same shape and any finite set $S$ of
singular-value indices,
write $\sigma_i(\mathbf{A})$ for the singular values indexed from $0$ in nonincreasing
order, padded by zeros beyond the smaller matrix dimension. The quantity
$\|\mathbf{E}\|_{(|S|)}$ is the Ky Fan norm of order $|S|$.
$$\sum_{i \in S} \lvert \sigma_i(\mathbf{A} + \mathbf{E}) - \sigma_i(\mathbf{A}) \rvert
  \le \|\mathbf{E}\|_{(\lvert S \rvert)} = \sum_{j < \lvert S \rvert} \sigma_j(\mathbf{E}) \,.$$

:::
