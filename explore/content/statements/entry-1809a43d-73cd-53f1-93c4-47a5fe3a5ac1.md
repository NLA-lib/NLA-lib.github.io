::: theorem result:subexponential-def name="A centred variable with a $\\psi_1$ bound is sub-exponential"
Under a probability measure,
if $X$ is a.e.-measurable, $\mathbb{E} X = 0$, $K > 0$, $e^{\lvert X\rvert / K}$ is integrable and
$\mathbb{E} e^{\lvert X\rvert / K} \le 2$, then $X$ is sub-exponential with variance
proxy <!-- value psiOneSubexponentialVarianceConstant -->$(32/e^2) K^2$ and
scale <!-- value psiOneSubexponentialScaleConstant -->$2K$; the constants are
`psiOneSubexponentialVarianceConstant` and `psiOneSubexponentialScaleConstant`.
This is Vershynin’s implication (iv) ⟹ (v), with the constants made explicit. The hypothesis $\mathbb{E} X = 0$ is needed (every `HasSubexponentialMGF`
variable is centred, `NLAlib.HasSubexponentialMGF.integral_eq_zero`); for a variable that is not
centred, use `NLAlib.hasSubexponentialMGF_sub_integral_of_integral_exp_abs_div_le_two`. A
$\psi_1$ Bernstein inequality is this bridge followed by
`NLAlib.HasSubexponentialMGF.measureReal_sum_ge_le_of_iIndepFun`.
:::
