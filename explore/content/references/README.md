# Explorer bibliography

These individual BibTeX entries are the canonical bibliography for the Explorer.
The initial 168 entries were copied from NLA-lib/NLAlib at commit
`e207eefa3d0c91354b42affc0bfcd982a3b05807`. The Lean repository retains its own
bibliography for its docstrings. It does not overwrite the website's entries.

A filename must match its citation key, for example `HornJohnson2013.bib`. Keep
existing keys stable. The References page supports editing, private drafts,
review, history, a full BibTeX download and individual copy dialogs. A published reference edit
updates every citation that uses its key. Extra fields remain in the raw BibTeX.

Math-source relationships, proof links and assessments are distinct from
bibliographic metadata. A citation alone does not satisfy a result's explicit
external-proof requirement.
