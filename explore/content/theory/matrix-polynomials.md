Polynomial approximation becomes an operator approximation by evaluating the same polynomial on a matrix. This is the bridge from a scalar approximation theorem to a Krylov or matrix-function error bound.

::: definition name="Evaluating a polynomial on a matrix"
For $p(t)=\sum_{j=0}^k c_jt^j$, set $p(\mathbf A)=\sum_{j=0}^k c_j\mathbf A^j$. Applying $p(\mathbf A)$ to $\mathbf b$ produces a vector in the Krylov space generated by $\mathbf A$ and $\mathbf b$. For Hermitian $\mathbf A$, functional calculus evaluates a scalar function on its real eigenvalues.
:::
