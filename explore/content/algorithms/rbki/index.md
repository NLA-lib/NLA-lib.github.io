## Definition

::: definition decl:NLAlib.rbki name="Randomized block Krylov iteration"
For $q$ blocks, form the column space generated by

$$\mathbf Y=[\mathbf A\mathbf\Omega,\ (\mathbf A\mathbf A^{\mathsf{H}})\mathbf A\mathbf\Omega,\ldots,(\mathbf A\mathbf A^{\mathsf{H}})^{q-1}\mathbf A\mathbf\Omega].$$

Return $\mathbf P_{\mathbf Y}\mathbf A$. The library's convention gives the zero approximation for $q=0$ and the ordinary range finder for $q=1$. Unlike subspace iteration, the block Krylov range retains all these powers.
:::
