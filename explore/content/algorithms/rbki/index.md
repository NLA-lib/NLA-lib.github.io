Project the matrix onto a block Krylov space generated from its sketch. This page concerns the untruncated projection. Its rank-$r$ truncation is a different output with its own statements, on the [late-truncated RBKI](/explore/algorithms/late-truncated-rbki/) page.

## Definition

::: definition decl:NLAlib.rbki name="Randomized block Krylov iteration"
For a matrix $\mathbf A$, a start block $\mathbf\Omega$ with $\ell$ columns, and $q$ blocks, form the column space generated by

$$\mathbf Y=[\mathbf A\mathbf\Omega,\ (\mathbf A\mathbf A^{\mathsf{H}})\mathbf A\mathbf\Omega,\ldots,(\mathbf A\mathbf A^{\mathsf{H}})^{q-1}\mathbf A\mathbf\Omega]$$

and return

$$\mathsf{rbki}(\mathbf A,\mathbf\Omega,q)=\mathbf P_{\mathbf Y}\mathbf A.$$

This is a deterministic function of $\mathbf A$, $\mathbf\Omega$, and $q$, over real or complex scalars. It is the zero matrix for $q=0$ and the range-finder approximation $\mathsf{rsvd}(\mathbf A,\mathbf\Omega)$ for $q=1$. Unlike subspace iteration, the block Krylov range retains all these powers.
:::

Singular values are indexed from zero, $\sigma_0\ge\sigma_1\ge\cdots$, so the best rank-$r$ spectral error is $\sigma_r$, and $[\mathbf A]_r$ denotes the rank-$r$ truncated singular-value decomposition. For a head index $h$ and a tail index $t$, the relative gap is

$$\gamma=\frac{\sigma_h-\sigma_t}{\sigma_h+\sigma_t},$$

with $\gamma=0$ when both singular values vanish.

## Components

The definition is a projection and prescribes no computation. The Golub–Kahan process computes factors whose product, in exact arithmetic, equals $\mathsf{rbki}(\mathbf A,\mathbf\Omega,q)$; that identity is stated on the process page and the scope of its program on the implementation page.

## Mathematical guarantees

These are upper bounds on the expected squared error for a real matrix $\mathbf A$ with $n$ columns and an $n\times\ell$ start block $\mathbf X$ with independent standard normal entries. They require a block wider than the tail index, $t+2\le\ell$ or $r+2\le\ell$. The gapped bounds are proved by comparing the block Krylov range with the range of a polynomially [filtered sketch](/explore/algorithms/filtered-randomized-svd/).

::: theorem result:rbki-gapped-error name="Expected spectral error with a gap" id=gapped-spectral
Let $q\ge1$, let $r=h+1$ be the number of head singular values, and let $t\ge r$ be a tail index with $t+2\le\ell$. Then

$$\mathbb E\|\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf X,q)\|_2^2\le\sigma_r^2+4e^{-8(q-1)\sqrt{\gamma}}\,\frac{t}{\ell-t-1}\,\|\mathbf A-[\mathbf A]_t\|_{\mathrm F}^2,\qquad\gamma=\frac{\sigma_h-\sigma_t}{\sigma_h+\sigma_t}.$$

No positivity of the gap or of $\sigma_t$ is assumed; the exponential factor decreases with the depth when $\gamma>0$.
:::

::: theorem decl:NLAlib.integral_frobNorm_sub_rbki_sq_le_singularGapRatio_of_hasLaw_gaussianMatrix name="Expected Frobenius error with a gap" id=gapped-frobenius
Under the same hypotheses ($q\ge1$, $r=h+1\le t$, $t+2\le\ell$),

$$\mathbb E\|\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf X,q)\|_{\mathrm F}^2\le\|\mathbf A-[\mathbf A]_r\|_{\mathrm F}^2+4e^{-8(q-1)\sqrt{\gamma}}\,\frac{t}{\ell-t-1}\,\|\mathbf A-[\mathbf A]_t\|_{\mathrm F}^2.$$
:::

::: theorem result:rbki-gapless-error name="Expected spectral error without a gap" id=gapless
Let $q\ge2$ and let $r$ be a target rank with $r+2\le\ell$ and $\sigma_r>0$. Then

$$\mathbb E\|\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf X,q)\|_2^2\le\sigma_r^2\exp\!\biggl(\frac{1}{16(q-1)^2}\log^2\!\Bigl(4\Bigl(1+\frac{r}{\ell-r-1}\,\frac{\|\mathbf A-[\mathbf A]_r\|_{\mathrm F}^2}{\sigma_r^2}\Bigr)\Bigr)\biggr).$$

No gap between singular values is assumed. For fixed $\mathbf A$ the right side tends to $\sigma_r^2$ as $q\to\infty$.
:::

::: theorem decl:NLAlib.integral_specNorm_sub_rbki_sq_le_one_add_sq_mul_of_hasLaw_gaussianMatrix name="Expected spectral error without a gap, relative form" id=gapless-relative
Let $q\ge1$, let $r$ be a target rank with $r+2\le\ell$, and let $\varepsilon>0$. Then

$$\mathbb E\|\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf X,q)\|_2^2\le(1+\varepsilon)^2\sigma_r^2+4e^{-8(q-1)\sqrt{\varepsilon/(2+\varepsilon)}}\,\frac{r}{\ell-r-1}\,\|\mathbf A-[\mathbf A]_r\|_{\mathrm F}^2.$$

No gap is assumed and $\sigma_r>0$ is not required. This bound and the preceding one are alternative regimes for the same error.
:::

The same result groups contain a form in every unitarily invariant norm for the Gram residual and forms that give a sufficient depth $q$ for a relative accuracy $\varepsilon$; they are in the Library.

## Block sizes below the target rank

The statements in this section hold for narrow start blocks, down to a single start vector. The tail bounds assume a relative gap $\Delta$ among the leading singular values and a depth $q$ at least the number of those singular values; the expectation bounds above need no gap $\Delta$ but a block of at least $t+2$ or $r+2$ columns.

::: theorem result:rbki-simulated-block name="The simulated block" id=simulated-block
Let $\mathbf A$ be a real or complex $m\times n$ matrix, $\mathbf\Omega$ a start block with $n$ rows, and $\mathbf H=\mathbf A^{\mathsf{H}}\mathbf A$. For all integers $s,q\ge0$,

$$\mathsf{rbki}\bigl(\mathbf A,\ [\mathbf\Omega,\mathbf H\mathbf\Omega,\ldots,\mathbf H^{s}\mathbf\Omega],\ q+1\bigr)=\mathsf{rbki}(\mathbf A,\mathbf\Omega,\ s+q+1).$$

Running $s+q+1$ blocks from $\mathbf\Omega$ gives the same approximation as running $q+1$ blocks from the wider block built from the first $s+1$ Krylov blocks of $\mathbf\Omega$. This is an identity of matrices, with no assumption on rank or on the block.
:::

::: theorem result:rbki-block-monotonicity name="A block with a larger range does at least as well" id=block-monotonicity
Let $\mathbf\Omega$ and $\mathbf\Omega'$ be start blocks with $\operatorname{range}(\mathbf\Omega')\subseteq\operatorname{range}(\mathbf\Omega)$; for example $\mathbf\Omega'$ consists of some columns of $\mathbf\Omega$. Then for every number of blocks $q$ and every index $i$,

$$\sigma_i\bigl(\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf\Omega,q)\bigr)\le\sigma_i\bigl(\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf\Omega',q)\bigr).$$

The comparison is for the untruncated approximation at the same depth $q$.
:::

::: theorem decl:NLAlib.measureReal_specNorm_sub_rbki_sq_gt_le_of_hasLaw_gaussianVector name="Single start vector with a gap: spectral-norm tail bound" id=single-vector-tail
Let $\mathbf A$ be a real matrix with $n$ columns and let $\mathbf x\in\mathbb R^n$ have independent standard normal entries. Fix a head of $r=h+1$ singular values, a tail index $t\ge r$, a depth $q\ge t$, and $\delta>0$. Suppose there is $\Delta>0$ with

$$\sigma_{i+1}^2\le(1-\Delta)\,\sigma_i^2\qquad\text{whenever } i+1<t,$$

and let $\gamma=(\sigma_h-\sigma_t)/(\sigma_h+\sigma_t)$. Then

$$\mathbb P\Bigl[\|\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf x,q)\|_2^2>\sigma_r^2+32\,e^{-8(q-t)\sqrt\gamma}\,\Delta^{-2(t-1)}\,\frac{t^3}{\delta^3}\,\|\mathbf A-[\mathbf A]_t\|_{\mathrm F}^2\Bigr]\le\delta.$$

The start block is the single column $\mathbf x$. The gap hypothesis concerns only $\sigma_0,\ldots,\sigma_{t-1}$: no gap between $\sigma_{t-1}$ and $\sigma_t$ and no positivity of $\sigma_{t-1}$ is assumed. The same result group, listed under Further results, contains the Frobenius-norm form and an expectation restricted to an explicit event.
:::

::: theorem decl:NLAlib.measureReal_specNorm_sub_rbki_sq_gt_le_of_hasLaw_gaussianMatrix name="Any block size with a gap: spectral-norm tail bound" id=any-block-tail
Let $\mathbf A$ be a real matrix with $n$ columns and let $\mathbf X$ be an $n\times\ell$ matrix with independent standard normal entries, $\ell\ge1$. With $r=h+1\le t\le q$, $\delta>0$, $\Delta>0$ satisfying $\sigma_{i+1}^2\le(1-\Delta)\sigma_i^2$ whenever $i+1<t$, and $\gamma=(\sigma_h-\sigma_t)/(\sigma_h+\sigma_t)$,

$$\mathbb P\Bigl[\|\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf X,q)\|_2^2>\sigma_r^2+32\,e^{-8(q-t)\sqrt\gamma}\,\Delta^{-2(t-1)}\,\frac{t^3}{\delta^3}\,\|\mathbf A-[\mathbf A]_t\|_{\mathrm F}^2\Bigr]\le\delta.$$

The right-hand side is the single-vector bound and does not depend on $\ell$. The Frobenius-norm form is listed under Further results.
:::

The deterministic bounds for a given start vector and a polynomial filter, in the spectral and Frobenius norms, and the exactness of the single-vector iteration at depth $q\ge t$ for a matrix of rank at most $t$ with $\sigma_0>\sigma_1>\cdots>\sigma_{t-1}$, are listed under Further results with their complete hypotheses.

## Lower bound

The following is a lower bound on the error of this particular method, not an upper guarantee. It holds for every start block of a given width, so it is not a statement about a random block.

::: theorem result:rbki-multiplicity-lower-bound name="A repeated singular value beyond the block size" id=multiplicity-lower-bound
Let $\mathbf A$ be a real or complex matrix and $\mathbf\Omega$ any start block with $\ell$ columns; no distribution and no rank condition is assumed. If indices $i,k$ satisfy $\sigma_i(\mathbf{A})=\sigma_{i+\ell+k}(\mathbf{A})$, then for every depth $q$,

$$\sigma_i(\mathbf A)\le\sigma_k\bigl(\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf\Omega,q)\bigr).$$

In particular, for $k=0$: if $\sigma_i=\sigma_{i+\ell}$, then $\sigma_i(\mathbf A)\le\|\mathbf A-\mathsf{rbki}(\mathbf A,\mathbf\Omega,q)\|_2$ for every $q$. When such a $\sigma_i$ exceeds $\sigma_r$, the spectral error stays above the best rank-$r$ error at every depth. This is a statement about the exact projection defining the method.
:::
