## 2. Certificate and DNS validation

After the region and secret ARN are known, request a public ACM certificate for
`api.nla-lib.org` in the same region as the API. Choose DNS validation. Add exactly
the validation CNAME generated by ACM at the current DNS provider. This validates
domain ownership; it does not direct API traffic or change the frontend's records.
[AWS certificate requirements](https://docs.aws.amazon.com/apigateway/latest/developerguide/how-to-specify-certificate-for-custom-domain-name.html)
