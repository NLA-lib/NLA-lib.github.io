NLA-lib

NLA-lib is a community library for numerical linear algebra. This site is a home for the project: what it is, how to use it, and how to contribute.

If this is something that resonates with you and you’re interested in contributing, please feel free to reach out! The project lives on GitHub at github.com/NLA-lib.
